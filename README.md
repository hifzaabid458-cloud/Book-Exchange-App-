# 📚 Book Exchange App

A Flutter-based peer-to-peer book exchange application that allows users to discover books, list their own books, save favorites, and send exchange requests to other readers.

## ✨ Features

- 🔐 User Sign Up and Login
- 🏠 Home screen with available books
- 🔎 Search books
- 📂 Book categories
- 📖 Detailed book information
- ❤️ Save favorite books
- ➕ Add new books
- ✏️ Edit listed books
- 🗑️ Delete books
- 🔄 Send book exchange requests
- 📥 Manage incoming exchange requests
- 📤 View sent exchange requests
- 📍 Location selection
- 👤 Profile management
- 🔑 Change password
- 🔔 Notification preference
- 🌙 Dark mode
- 🖼️ Local book cover images
- 💾 Local data persistence using SharedPreferences

## 💾 Data Storage

The application uses SharedPreferences for local storage.

User account information and book data can be stored locally so that the application can retain data between sessions.

## 🚀 How to Run

### Prerequisites

Make sure you have:

- Flutter SDK installed
- Dart SDK
- Android Studio
- An Android emulator or physical Android device

### Installation

Clone the repository:

git clone https://github.com/hifzaabid458-cloud/Book-Exchange-App-.git

Navigate to the project:

cd Book-Exchange-App-

Install dependencies:

flutter pub get

Run the application:

flutter run
